# Credits

Third-party material vendored into this repository, and the terms it is used
under. Nothing here is fetched at runtime — every file is committed, so a clean
checkout works with no network, no npm and no build step.

## Lucide

- **What:** the icon set (2007 icons), used for page icons and all UI chrome.
- **Version:** 1.28.0
- **Home:** https://lucide.dev
- **Licence:** ISC, with a subset of icons derived from
  [Feather](https://feathericons.com) under MIT
- **Copyright:** ISC portions © 2026 Lucide Icons and Contributors;
  the Feather-derived icons © 2013–present Cole Bemis
- **Files:** `app/Data/lucide-icons.php`, `public/assets/icons/lucide.svg`,
  `public/assets/icons/lucide-index.json`, generated by `scripts/build-icons.php`

**The full licence text — both licences, and the list of which icons are
Feather-derived — is at `public/assets/icons/LICENSE-lucide.txt`**, copied
verbatim from the upstream package. It is not reproduced here, so that there is
exactly one copy and no chance of this file drifting out of date with the terms
actually shipped. Roughly 110 icons carry the MIT notice, including several this
app uses in its own chrome (`check`, `chevron-down`, `search`, `lock`, `log-out`,
`trash-2`, `x`, `info`, `moon`).

Both licences require the copyright and permission notice to travel with the
copies, which is why `scripts/build-icons.php` copies `LICENSE` into
`public/assets/icons/` rather than relying on "we downloaded it once".

Note the icon set is **not** shipped to readers wholesale — see `docs/ICONS.md`.
Only the icons a page actually uses are inlined into it.

## emojibase

- **What:** emoji names and search keywords (CLDR annotations packaged as JSON),
  used for the picker's emoji tab.
- **Version:** 17.0.0 (data filtered to Emoji 15.1 and below)
- **Home:** https://emojibase.dev
- **Licence:** MIT
- **Files:** `public/assets/icons/emoji.json`, generated by
  `scripts/build-emoji.php`

Only the generated list ships. The emoji characters themselves are Unicode and
carry no licence; what emojibase provides is the names and keywords, and only
the English set is vendored.
